# BRACE-MSI 正式候选系统实施计划

本计划落实已锁定的BRACE-MSI V4.1，不构成新方案版本。执行基线为
`27a546e`，本地代理密封段已消费，后续开发不得据其结果选型或重跑。

## 全局约束

- 官方SDK字段、标签权限和评分公式保持未知，只实现可替换边界。
- 训练与选型只使用合法开发段；第三任务仅用明确标注的合成流做协议验收。
- 正式镜像不携带数据、模型权重、密钥或外部模型服务依赖。
- 每项功能测试先行；一个任务完成、全套测试通过并提交后才进入下一项。
- 本计划完成前保持`main@27a546e`为稳定基线，开发发生在当前任务分支。

## Task 1：统一任务引导、模型池与模型注册表（SYS-001）

实现平台无关的任务描述、输入校验、未知同领域任务初始化、CPU模型能力声明、
分类/回归模型池、候选配置和原子模型注册/回滚。批量模型禁止调用
`partial_fit`，持久化后预测必须一致。

验收：模型池覆盖SGD、线性批量模型、HistGradientBoosting和ExtraTrees；任务不兼容
时拒绝复用；注册、加载和回滚测试通过；完整测试通过。

## Task 2：证据路由、预算动作选择与有限HPO（SYS-002）

扩展证据为数据质量、性能、协变量漂移、动作历史和资源余量；建立动作白名单、
训练前预算分配、经验回放、模型族切换、有限候选HPO和无收益自动停止。候选失败
不得污染稳定模型，至少三次真实候选事件可由配置约束。

验收：固定证据选择固定动作；HPO受次数/时间/样本预算约束；连续无收益停止；
回放有上限；至少一个故障候选自动拒绝并保留稳定模型；完整测试通过。

## Task 3：无人值守Harness、恢复与记录接口（SYS-003）

将模拟SDK、TaskBootstrap、流管理、决策、训练、门控、注册表和报告事件组合为
统一Harness。实现检查点、幂等恢复、失败分类、CLI、公开记录接口和私有JSONL审计；
SwanLab不可用时只写可同步的本地聚合队列，不冒充云端记录。

验收：两种模拟协议均可运行；进程中断后从最近已提交批次恢复而不重复训练；
日志不含原始特征/逐样本标签/密钥；CLI非交互运行；完整测试通过。

## Task 4：交付包装与静态HTML报告（SYS-004）

提供Dockerfile、锁定依赖、一键PowerShell/Unix入口、运行配置校验、许可证清单、
静态HTML报告和官方适配器接入说明。Docker上下文不得包含数据、产物或权重。

验收：CLI和一键脚本完成Smoke；HTML离线打开且展示任务、阶段、动作、门控和资源；
Docker构建上下文小于2GB；若本机无Docker，明确记录实际构建为阻塞而不伪造结果。

## Task 5：三任务模拟正式评测与资源验收（SYS-005）

预注册后运行Gas开发流、FD001开发流和一个合成轴承分类漂移流。每个任务完成初始化、
预测、合法反馈、至少三次候选评估、部署或拒绝、故障回滚和结束报告；不打开原密封段。
使用操作系统亲和性/环境限制或等价可核验方式约束4核，监测RSS低于8GB。

验收：无人干预完成三任务；三次候选要求、恢复测试、资源限制、日志验证和HTML报告
均通过；形成模拟评测证据包；全部自动化测试通过；仅官方SDK/数据/评分优化留作阻塞。
