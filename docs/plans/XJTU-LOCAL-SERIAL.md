# XJTU-SY本地串行训练实施计划

本计划执行`XJTU-LOCAL-001`，事实与边界以`SOURCE_REGISTRY.md`、`DECISION_LOG.md`和`EXPERIMENTS.md`为准。

1. 以TDD实现XJTU归档清单、轴承分组、独立CSV特征提取、RUL标签和缓存装载；验证分组互斥且输入特征不含轨迹总长度或未来信息。
2. 编写可恢复串行运行器。每个阶段原子更新`status.json`，逐轴承保存压缩特征缓存，逐轮保存JSON/JSONL与资源指标。
3. 在D盘派生目录校验并解压原始分卷，不修改六个RAR；按轴承构建缓存，失败可从最后完整轴承恢复。
4. 依次运行三个静态CPU强基线、性能触发和BRACE。只在前三轮完成后进行一次健康检查；其后让隐藏后台进程继续。
5. 全部队列完成后执行机器验收、回归测试，更新SSOT与聚合结果并提交Git。若会话提前结束，新会话只需读取状态文件和后台日志恢复。

完成证据至少包括：固定提交、配置和数据哈希、分组摘要、缓存清单、状态文件、逐轮有限指标、资源记录、后台PID/退出码、测试命令及结果。
