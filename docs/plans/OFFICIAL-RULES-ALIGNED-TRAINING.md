# 最新官方规则对齐训练实施计划

## 目标与边界

依据O-PLATFORM-001至004，在不等待平台训练包的情况下完成三任务训练阶段工程验证。平台初始权重缺失时使用参数量精确匹配的本地重建MLP检查点；产物必须标记`official_checkpoint=false`，不得进入平台成绩叙述。展示材料不在本计划范围。

## 执行任务

1. 通过TDD增加MLP模型族、参数计数、检查点保存/加载和官方指标（Macro-F1、RMSE/MAE、NASA非对称分）。
2. 通过TDD构造三任务10轮开发流：Gas连续块、FD001设备分组、XJTU轨迹进度阶段；验证样本和组身份互斥且密封段未加载。
3. 实现原子、可恢复的9实验串行监督器：每任务一次本地初始检查点，三策略共享；逐实验状态、日志、模型、资源和失败证据落盘。
4. 实现机器验收与聚合分析，分别报告平台35分所关心的性能增益、恢复速度、稳定性和资源，但不自创官方总分。
5. 在干净提交上启动隐藏后台进程。确认前三个静态实验后停止持续监控；后续进程独立完成，状态可由10分钟轮询恢复。
6. 全部完成后运行全量回归、机器验收和结果审计，更新SSOT与交接文档并提交Git。平台训练包到达后另建正式实验ID替换检查点。

## 完成证据

- 四张截图哈希与来源登记；
- 固定代码提交、配置、数据哈希和参数计数；
- 9个实验×10批次的结果、资源与审计；
- 前三实验健康检查记录、后台PID和终态；
- 自动聚合JSON/HTML/Markdown；
- 机器验收、完整测试、编译与干净工作树。
