# BRACE-MSI 作品说明书

> 当前提交候选：BRACE-MSI 0.11.0rc1（Competition Core RC）
> 文档日期：2026年11月21日
> 证据边界：本文区分本地验收、公开开发实验和官方历史试运行；不把本地结果表述为隐藏测试成绩。

## 1. 赛题理解与作品目标

工业传感器老化、设备磨损和工况变化会使数据分布及输入—输出关系持续变化，静态模型因而逐步失准。BRACE-MSI不是单独训练一个高分模型，而是一套在平台父检查点和当前合法数据上无人干预运行的工业模型自主迭代Harness。

系统面向分类和回归数值表格任务，未知任务不依赖Gas、Bearing或Engine名称路由。每轮都完成一次真实候选训练，再依据本地合法评估决定部署候选、保留父模型或回滚。平台负责提供数据、父检查点、模型服务和最终评分；BRACE-MSI在镜像内部完成实验设计执行、候选评估、模型选择、父链续接和审计记录。

| 目标 | 实现原则 |
|---|---|
| 自主实验 | Qwen读取任务画像和聚合历史，提出注册化训练方案 |
| 真实性能 | 每轮从平台父checkpoint真实续训，不用另一套模型冒充续训 |
| 泛化能力 | 依据任务类型、指标方向、特征和历史表现决策，不按数据集名称硬编码 |
| 安全可控 | Harness核对数据、父链、数值方向、预算和产物，拒绝非法或退化选择 |
| 资源效率 | CPU训练、小型checkpoint、候选有界，记录时间、内存和模型调用 |

## 2. 总体架构

正式运行链为：

`OfficialRoundAdapter → TaskProfiler → QwenExperimentAgent → CandidateTrainer → LocalEvaluator → ArtifactSelector → RoundRecorder`

| 组件 | 主要职责 |
|---|---|
| OfficialRoundAdapter | 使用官方SDK 1.0.2读取本轮数据、父checkpoint、历史和输出目录 |
| TaskProfiler | 从任务合同和数据统计识别分类/回归、指标方向、特征规模和历史状态 |
| QwenExperimentAgent | 每轮两次调用平台Qwen：先提出实验，再结合候选结果给出部署建议 |
| CandidateTrainer | 从父checkpoint出发执行注册化CPU训练，输出兼容`checkpoint.npz` |
| LocalEvaluator | 在同一合法作用域计算父模型、候选和可恢复历史模型的主辅指标 |
| ArtifactSelector | 确定性核对指标方向和数值关系，防止大模型算术或结构化决策错误 |
| RoundRecorder | 原子保存模型、调用ID、候选参数、指标、资源、理由和父链状态 |

Qwen负责像算法工程师一样提出假设和解释结果，但没有任意代码、Shell、数据路径或核心门控修改权。Harness负责把建议限制为可执行的注册化方案，并确保平台要求、父链和模型产物始终有效。

## 3. 每轮自主优化流程

每个数据集执行十轮；每轮至少训练一个真实候选。`retain`不是跳过训练，而是完成实验后认为候选不值得部署。

1. 读取父模型、当前合法数据、任务画像和已提交历史；
2. 第一次调用Qwen，输出结构化实验假设及注册recipe；
3. Harness校验recipe、参数、数据边界和运行条件；
4. 从父checkpoint训练候选，保存训练损失、CPU、墙钟、RSS和checkpoint哈希；
5. 在相同合法作用域评估父模型、候选及允许回选的历史模型；
6. 第二次调用Qwen，综合主指标、辅助指标、资源和历史提出部署/保留/回滚建议；
7. ArtifactSelector确定性核对指标方向、可比作用域和模型可加载性；
8. 原子保存获选checkpoint、实验收据和状态，进入下一轮。

对于未知但格式相同的工业任务，系统首先依据父checkpoint中的任务合同确定分类或回归，再根据当前数据和历史表现选择方案。若Qwen不可用或输出非法，注册表会回退到真实`native_current`候选训练；失败不会破坏父模型。

## 4. 性能方法与泛化策略

正式候选保持平台父模型的原生MLP schema和Adam状态，避免更换模型家族导致续训协议不兼容。当前注册方案覆盖当前批续训、合法历史数据续训、类别权重、稳健回归损失、有限epoch/学习率变化和历史模型回选；任何模型回选都必须先恢复并在当前相同作用域重新评估。

公开A/B/C仅用于开发和验证决策链。冻结开发矩阵的描述性结果如下，不能等同于隐藏成绩：

| 任务 | 指标 | 静态父模型 | 冻结开发候选 | 相对变化 |
|---|---|---:|---:|---:|
| A 气体识别 | Macro-F1 ↑ | 0.714030 | 0.730826 | +2.35% |
| B 轴承健康 | RMSE ↓ | 681.159833 | 680.012612 | -0.17% |
| C 发动机寿命 | RMSE ↓ | 52.868573 | 51.877279 | -1.88% |

项目还小规模检验了L2-SP、SAM-Adam和AdamW。三种方法没有形成跨任务正向趋势，故未进入正式RecipeRegistry，也没有为追求局部指标而重建镜像。历史异构树模型和PaperFusion同样只保留研究证据，正式提交仍严格输出父checkpoint兼容的原生模型。

泛化策略的重点不是固定某组超参数，而是让Qwen依据任务画像和历史在受控方案中选择，并由同作用域确定性比较防止错误部署。该设计允许已知任务使用真实数据证据，同时对同格式未知任务提供不依赖名称的回退路径。

## 5. PyTRiO、模型服务与实验记录

正式提交选择平台允许的基础模型`Qwen/Qwen3.5-4B`。镜像不安装PyTRiO客户端、不携带Tokenizer、Sampler或API Key，而是通过官方Harness SDK的`rnd.model()`调用平台绑定模型；这与平台正式计量和隔离方式一致。

开发阶段曾使用PyTRiO对决策Agent进行有界LoRA实验并由SwanLab记录。最新Competition Agent Sampler在独立留出上总体严格策略为87.5%，未达到预注册90%采用门，因此没有因已经付费训练而降低标准，正式版本继续选择平台已校验的基础Qwen。

SwanLab只记录聚合配置、损失、指标、资源和采用决定，不记录工业逐样本特征、标签、预测、API Key或完整私有权重路径。公开研究记录用于证明开发过程；正式平台十轮运行产生的工业模型收据以平台报告和作品版本为准。

| 项目 | 当前选择 |
|---|---|
| 平台模型 | `Qwen/Qwen3.5-4B`基础模型 |
| 正式调用 | 官方SDK `rnd.model()` |
| PyTRiO用途 | 镜像外Agent训练与独立验证 |
| SwanLab | 脱敏聚合实验记录，不上传私有样本 |
| 失败降级 | 非法建议回退真实原生续训，非法部署保留父模型 |

## 6. 安全、资源与工程验收

安全边界只处理不可违反的事实，不替代Agent进行正常研究判断：数据和路径必须合法；父checkpoint哈希与状态链一致；候选必须可加载且预测有限；比较必须使用同一验证作用域；主指标方向和数值关系不能算反；输出必须满足官方`checkpoint.npz`及64 MiB产物约束。

## 8. 主要创新与工业价值

- **真实实验而非聊天建议：** 每轮建议都必须落到父checkpoint兼容候选训练、指标和收据。
- **智能决策与事实校验分工：** Qwen提出假设和解释，Harness核对数据、指标方向、资源和产物。
- **未知任务能力画像：** 根据任务合同和数据证据选择方案，不依赖数据集名称。
- **同作用域历史模型回选：** 历史模型必须在当前作用域重新评估，避免跨轮指标不可比。
- **正式与本地镜像分离：** 模拟器、测试和研究依赖不会进入上传镜像。
- **负结果驱动的工程收敛：** 未达门Sampler、异构模型和成熟优化器均被真实实验否决，正式系统保持最小可靠边界。

BRACE-MSI最终交付的不是一组固定超参数，而是一套能在有限CPU和模型调用预算下持续提出实验、真实训练、评估选择、继承父链并留下完整证据的工业模型自主迭代系统。
