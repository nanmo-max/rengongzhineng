# BRACE-MSI Competition Core 正式架构规格

日期：2026-11-20  
状态：`READY_FOR_USER_REVIEW`  
范围：正式竞赛运行核心、本地验证体系、PyTRiO Agent与发布边界

## 1. 目标

BRACE-MSI交付一个由官方平台直接调用的无人值守工业模型自进化Harness。平台可能下发A/B/C之外的新工业任务，但输入保持官方训练包与`contest.harness.workspace.v2`同类合同：任务合同、带标签训练/验证数据、父checkpoint、历史与状态接口均可用。系统不得依赖Gas、Bearing或Engine名称选择方法。

每个任务执行十轮。每轮必须完成至少一次真实、父checkpoint兼容的候选训练，再依据本轮合法可见指标选择候选、父模型或可恢复历史模型。`retain`只表示候选已经训练和评估但未部署，不能在训练前跳过实验。

成功标准按优先级为：

1. 正式上传镜像严格符合官方SDK、父链、产物、预测与容器要求并能够完成运行；
2. Qwen真实参与每轮实验设计和结果分析，模型调用ID与Token可审计；
3. 已知任务及新的同格式分类/回归任务均能自动识别、真实续训和正确选择；
4. 工业模型主指标、最差阶段、稳定性与资源效率得到真实改善；
5. PyTRiO训练、SwanLab记录、源码提交、Docker归档和报告具有同一版本血缘。

## 2. 证据边界

### 2.1 官方已确认

- 正式协议为`contest.harness.workspace.v2`，模型访问只经宿主`rnd.model()`或`rnd.transport()`；完成记录必须引用真实`model_call_ids`。
- 每轮可读取任务合同、公开训练/验证行、父产物、历史与状态；可提交候选并选择父、候选或已声明历史产物。
- 正式预测逐行输出；分类与回归格式由官方SDK约束。
- 候选必须延续官方父checkpoint，产物总量不超过官方限制；隐藏数据不挂载到训练容器。
- 真实试运行已证明三任务十轮、双阶段模型调用、真实候选训练和最终隐藏预测能够完成。

### 2.2 用户确认的设计输入

- 正式隐藏评测可能包含A/B/C之外但与当前训练包同格式的新工业任务；官方直接调用镜像，任务内容事前不可见。
- 父模型、带标签数据、历史数据与实验历史可用，应进入后续实验设计与合法回放。
- 每轮必须真实训练；不允许Qwen在训练前用`retain`否决实验。
- 不增加非官方Token、候选数、epoch、提升比例或其他硬上限；只服从官方当轮资源和产物约束。
- 本地测试镜像与正式上传镜像必须独立构建和审计。
- PyTRiO训练的Qwen Agent是正式方案组成部分。

### 2.3 仍由适配层吸收的不确定性

- 当前SDK 1.0.2的`dataset_key`取值为A/B/C。正式算法把它仅视为路由标识，不据此选择方法；任务语义来自`task_contract`、父checkpoint和数据画像。若官方以更新SDK表达新任务，只替换SDK适配层。
- 隐藏数据分布和评分公式权重不可见。本地模拟不预测隐藏数值，只验证协议、训练、选择和跨划分趋势。

## 3. 唯一运行架构

正式运行链只有以下七个职责单元：

1. **OfficialRoundAdapter**：封装官方SDK，提供任务合同、当前训练/验证数据、父产物、历史、状态、模型网关、候选提交和完成事务。
2. **TaskProfiler**：从任务合同、父checkpoint与数据摘要识别分类/回归、主指标及方向、输出结构、特征与标签画像、分组/时间信息；不得按数据集名称路由。
3. **QwenExperimentAgent**：第一次调用读取任务画像与历史，提出本轮假设、recipe和配置；第二次调用读取真实评估结果，解释并提出部署、保留或回滚意见。
4. **CandidateTrainer**：从本轮父checkpoint出发，使用当前数据和合法历史数据执行真实续训；保存模型、优化器、预处理与训练状态。
5. **LocalEvaluator**：在同一当前验证作用域评价父、候选和可恢复历史模型，计算主指标、辅助指标和资源数据。
6. **ArtifactSelector**：把指标名称、方向、数值关系和产物合法性作为确定性事实，校验Qwen选择；在同作用域合法模型中完成最终选择。
7. **RoundRecorder**：保存假设、真实执行参数、指标、资源、模型调用ID、选择理由、父链、候选与历史引用，并原子提交状态。

Qwen不能直接改写SDK适配、指标实现、父链、预测入口或正式镜像文件。

## 4. 单轮数据流

每一轮固定执行以下语义，不允许训练前提前结束：

1. 读取当前任务合同、父checkpoint、训练/验证数据、历史和状态。
2. 生成不含逐样本敏感数据的任务画像、历史摘要和可用训练能力清单。
3. 第一次宿主Qwen调用生成结构化实验提案：假设、recipe、参数、数据使用方式和预期改善指标。
4. 验证提案能映射到已实现且父checkpoint兼容的训练能力。非法或不可执行回复改用确定性备用实验，但本轮仍真实训练。
5. 至少生成一个真实候选。若Qwen和官方资源明确支持额外候选，可继续实验；代码不设置非官方固定上限。
6. 在同一当前验证作用域评价父、全部候选和可恢复历史模型，并记录CPU、墙钟、RSS、Token与模型大小。
7. 第二次宿主Qwen调用读取机器生成的指标事实，提出`deploy / retain / rollback`意见与理由。
8. 核对指标方向、同作用域可比性、模型可加载性、有限输出、父链与官方资源约束。Qwen不能把主指标明确更差的候选误判为更优。
9. 选择候选、父模型或已在当前验证作用域重新评价的历史模型，保存状态并完成本轮。

若第二次Qwen调用失败，Harness仍根据同作用域主指标、辅助指标与成本完成确定性选择并记录模型服务故障。模型调用是否满足正式回合要求继续服从官方SDK。

## 5. 任务自适应与训练能力

统一的是实验过程与证据合同，不是超参数。TaskProfiler和Qwen可基于可观察事实组合以下父checkpoint兼容能力：

- 通用：学习率、epoch、batch、优化器状态延续、正则化、早停、权重平均、父候选权重插值、当前数据与历史回放；
- 分类：类别权重、平衡采样、交叉熵与已实现的稳健分类损失、校准；
- 回归：目标缩放、合理目标约束、MSE、MAE、Huber、非对称损失及任务合同声明的辅助指标；
- 数据：缺失值处理、使用父状态或当前合法训练集合拟合的标准化、分组/时间感知训练划分。

正式线不把异构树模型或全新网络冒充父模型续训。若未来官方明确允许结构变化，必须通过新的父链与产物契约进入，而不是在本规格中预先放宽。

训练能力采用注册式实现：每项recipe声明适用任务类型、需要的数据、修改的训练参数、父checkpoint兼容条件和实际执行收据。Qwen只能选择已注册能力，不直接执行任意代码。

## 6. 历史数据、历史模型与回滚

- 当前轮可使用平台提供的历史记录、历史数据和状态；回放数据必须来自已经合法开放的轮次。
- 当前父模型始终是本轮续训起点。历史模型只有在官方SDK声明可恢复、摘要校验通过并在当前验证作用域重新评价后，才能参与本轮选择。
- 不直接比较不同轮次、不同验证作用域的历史最高数字。
- `retain`表示本轮候选训练完成但最终继续使用父模型。
- `rollback`表示选择一个已恢复并在当前作用域重新评价的历史模型；若没有这种模型，不能把保留父模型伪称回滚。

## 7. 指标与模型选择

- 任务合同给出的主指标决定基本排序及方向；辅助指标只在主指标接近或任务合同要求时参与权衡。
- 分类至少记录主指标及Accuracy；回归至少记录主指标及MAE，并在任务合同提供时记录NASA等指标。
- Harness负责计算指标事实和同作用域有向收益；Qwen负责解释、权衡和提出选择。
- 不设置固定5%提升、Anchor零退化或其他非官方门槛。
- 官方硬约束只包括SDK协议、父链、产物、模型可加载、预测格式、有限数值和平台下发资源。

## 8. PyTRiO Agent与SwanLab

PyTRiO训练位于正式镜像之外：

1. 从A/B/C真实实验轨迹、新同格式任务轨迹和已登记错误案例生成脱敏训练样本；不包含隐藏数据、逐样本特征或密钥。
2. 使用PyTRiO对官方允许的Qwen基座执行LoRA/SFT，使其学习任务画像解析、实验提案、指标方向、历史利用和部署判断。
3. 使用未参与训练的任务与数值组合评价结构有效率、实验可执行率、指标判断和部署安全；保留基础模型对照。
4. 保存PyTRiO运行ID、基座、LoRA配置、训练步数、损失、Token、费用、Sampler路径和留出结果。
5. 只有提交页校验通过的持久化Sampler才能绑定正式运行；正式镜像仍只通过`rnd.model()`访问宿主管理模型，不内置PyTRiO SDK、Tokenizer、Sampler或API Key。

SwanLab记录PyTRiO训练和最终工业模型重跑的脱敏聚合指标。正式离线镜像只产出本地审计记录，镜像外工具再同步至SwanLab。

## 9. 双镜像与供应链

### 9.1 本地测试镜像

本地测试镜像可包含官方宿主模拟器、自动测试、故障注入、A/B/C和同格式替代任务适配、HTML报告、PyTRiO验证入口及SwanLab离线记录工具。它必须显著标记`LOCAL_TEST_ONLY`，禁止上传比赛平台。

### 9.2 正式上传镜像

正式镜像从独立白名单清单构建，只包含官方固定入口、官方SDK、Competition Core运行模块、NumPy和必要依赖。禁止包含：

- 训练/测试数据、工业模型权重和本地产物；
- 模拟宿主、测试套件、HTML报告和开发脚本；
- PyTRiO/SwanLab私有客户端、Tokenizer、Sampler与凭据；
- 原始提示、逐样本记录、密钥和本地缓存。

正式镜像必须由`docker save`生成可重载归档。源码提交、依赖锁、镜像ID、归档SHA-256、PyTRiO模型选择和SwanLab记录必须由同一发布清单绑定。

## 10. 本地验证与实验顺序

实现前为每个实验登记ID、数据边界、比较对象和产物目录。训练按以下顺序执行：

1. **协议Smoke**：分类/回归各一轮，确认官方SDK、双Qwen调用、父续训、候选提交、选择与预测。
2. **十轮集成**：A/B/C各十轮，每轮真实训练，验证历史、父链、部署/保留/回滚和报告。
3. **未知任务验证**：使用未参与任务专属规则形成的同格式分类和回归任务，验证任务识别和训练能力迁移。
4. **性能开发**：在训练内部的分组/时间划分上比较注册recipe，保留正负结果；公开验证可模拟平台当轮评价，但不得冒充独立隐藏证据。
5. **PyTRiO训练与留出**：冻结语料后训练Sampler，并在新任务/新数值组合上与基础模型比较。
6. **双镜像验收**：本地测试镜像完成全部测试；正式镜像执行官方SDK、十轮、逐行预测、4核8GB、断网、非root、只读根、禁入扫描及`docker save/load`。
7. **最终记录**：用冻结代码重新运行工业模型训练，生成SwanLab、HTML、机器JSON、Git和发布清单。

本地模拟用于发现工程和方法缺陷，不声称复制隐藏数据或正式数值。官方试运行只在正式镜像通过全部本地门且获得单独授权后执行。

## 11. 错误处理

- Qwen提案非法：记录原回复摘要与调用ID，执行确定性备用真实训练。
- 候选训练失败：保留失败收据；如官方剩余资源允许，运行兼容备用recipe；不得提交损坏产物。
- 评估失败或非有限：候选不可选择，但本轮仍完成第二次模型调用和状态记录。
- Qwen部署意见与指标事实冲突：按确定性指标事实修正，记录requested/applied差异。
- 历史模型不可恢复或作用域不一致：排除该历史模型，不影响父/候选比较。
- 平台接口或父链错误：失败关闭，不猜测字段或绕过官方SDK。

## 12. 验收

### 12.1 功能

- 未知同格式分类/回归任务能够从合同、父checkpoint和数据自动识别；
- 每任务十轮，每轮至少一个真实候选和两阶段Qwen证据；
- 父、候选与合法历史模型在同一当前验证作用域选择；
- 部署、保留、真实回滚、恢复和逐行预测可复算；
- 历史数据使用与父链均有收据。

### 12.2 性能与资源

- A/B/C及未知同格式验证任务均报告静态父模型、最终模型、逐轮主辅指标、最差阶段、恢复、CPU、墙钟、RSS、Token和模型体积；
- 选择不依赖跨作用域历史最高值；
- 不以预设百分比替代真实比较，也不把未改善包装为正向结果；
- 所有失败和负结果保留。

### 12.3 发布

- 正式镜像只含白名单文件且不含本地测试资产；
- 官方SDK测试、完整十轮、Docker限制、禁入扫描和重载通过；
- PyTRiO模型在提交页校验通过并由正式发布清单绑定；
- SwanLab、Git、镜像与报告指向同一源码提交和配置；
- 未经本地完整验收和用户单独授权，不上传或消耗官方试运行。

## 13. 明确删除的旧复杂度

新核心不采用四缓冲区强生命周期、ActionValueTable/Bandit、影子收益、固定动作日程、固定提升比例、Anchor零退化、任意代码补丁或按A/B/C名称路由。历史实现和证据不删除，但不进入新正式运行路径，除非后续真实实验重新证明必要性。

## 14. 实施边界

本规格批准后才编写实施计划。实施从当前已通过官方SDK和容器验证的最小正式入口继承，不原地修改冻结`0.10.6rc1`，也不把D-091失败研究组合带入新候选。每项实现先有失败测试，再做最小代码；本地测试镜像和正式上传镜像从第一天起使用不同构建清单。
