# BRACE-MSI 受控双闭环设计

## 1. 目标与轮次语义

系统面对按顺序开放的十个数据批次。每个批次恰好触发一次决策层迭代；第`t`轮只能读取当前批次和已提交的`1..t-1`历史。轮内固定顺序为：稳定模型预测并提交、合法标签反馈、证据分析、决策、零至两个候选执行、门控部署或拒绝、原子提交历史、请求下一批。

执行候选不是固定菜单。第二候选只能在首候选被拒或收益不足、存在机制不同的新证据且预算充足时运行。全程至少保留三次真实“历史—假设—实验—评估—决策”链，`NOOP`不计入。

核心支持未知数值表格分类和回归；时序能力只保留接口，正式协议未提供合法顺序或分组时关闭。共享的是决策算法、预算、安全、审计和接口，不按Gas、Bearing或Engine名称硬编码动作。

## 2. 两层闭环

### 2.1 决策层

每批始终运行确定性证据分析。轻量`ActionValueTable`按当前任务独立保存任务画像、动作收益/成本区间、失败率、接受率、支持样本数和归因置信度。A/B/C只形成高不确定弱先验，隐藏任务真实结果可快速覆盖。

明显性能退化、复杂漂移、连续失败或Pareto动作无法区分时调用`Qwen/Qwen3.5-4B`。Qwen只提出结构化动作、参数、工具或受限插件补丁；BRACE拥有合法性、预算、排序、执行和部署权限。服务异常时限时重试一次，仍失败则记录收据并确定性降级。

### 2.2 执行层

白名单动作是`NOOP`、`RECALIBRATE`、`INCREMENTAL_UPDATE`、`REPLAY_REFIT`、`FAMILY_SWITCH`、`BOUNDED_HPO`、`REGISTERED_PLUGIN`和`ROLLBACK`。每批最多两个候选、全程默认最多八个；单批最多使用初始CPU预算20%，最后三批预留至少25%。小型HPO最多三个内部试验并全部计入资源。

## 3. 数据能力边界

### 3.1 四缓冲区

- `AnchorBuffer`：固定历史保护集，只评估，永不训练。
- `UpdateBuffer`：当前批允许训练的数据。
- `GateBuffer`：当前轮一次性候选验证数据；本轮绝不训练或拟合预处理器。
- `ReplayBuffer`：已合法开放、完成一轮隔离且允许历史回放的数据。

候选训练集合只能是`UpdateBuffer`或`UpdateBuffer + eligible ReplayBuffer`。预处理、标准化、缺失填补、特征选择、样本权重和目标变换只拟合候选实际训练集合。

首批合法训练数据默认按组或顺序抽取10%为Anchor。每个反馈批默认80%进入Update、20%进入Gate；Gate在本轮结束后隔离一轮，之后才能进入Replay。分类尽量分层，回归按设备组或连续块；样本不足时降低门控置信度并保留稳定模型。

### 3.2 物理未来隔离

`RuntimeAdapter`是唯一接收官方事件的组件。每轮生成只读`RoundDataManifest`，记录可访问批次、样本摘要、文件哈希、用途和访问清单。执行层只获得当前轮物化目录或不暴露原始路径的`DatasetHandle`；未来批次不物化，训练子进程不得获得官方原始数据根。

若正式SDK只提供包含未来批次的完整目录且无法建立路径级隔离，适配器必须失败关闭或切换为事件负载模式，不能声称防泄漏。测试必须放置未来诱饵文件并证明当前轮训练器和插件不可发现或读取。

模型预测输入只能来自`inputs`。`id/meta`只用于合法分组、顺序和审计。

## 4. 收益归因和安全部署

候选部署后保留直接前任模型作为一轮影子模型。下一批由新模型产生正式提交；旧模型只做本地影子预测。标签开放后在相同样本上计算配对指标差，作为上一动作的主要延迟收益。本轮Gate结果只作较弱即时证据。

影子预测资源必须计量。若SDK禁止额外推理或预算不足，则关闭影子机制、退回历史基线估计并把归因标为低置信度。

SafetyGate同时检查数据合法性、输出可用性、资源、Gate表现、Anchor退化、模型可加载性和回滚能力。评分公式未知时维护性能—成本Pareto集合，不自创官方总分。

## 5. 模型和插件

模型按注册门分层：Tier 0为官方初始模型与Logistic/Ridge/SGD回退；Tier 1为HistGradientBoosting和ExtraTrees；Tier 2为CatBoost等外部模型。Tier 2必须通过4核8GB、依赖体积、输入契约、训练耗时、序列化加载、预测协议和产物兼容验收后才能启用。增量动作只能用于真实支持增量或兼容续训的模型；集成最多两个模型且必须证明互补。

Qwen生成的补丁只能进入预定义纯函数插件槽，例如特征变换、样本权重或预测后处理。补丁不能修改SafetyGate、RuntimeAdapter、数据边界、BudgetLedger、注册表、回滚、审计或状态机。必须同时通过AST白名单、固定签名、禁止导入/文件/网络/子进程/反射/动态执行、隔离子进程、CPU/内存/超时、形状/有限值、确定性和差异测试。任一失败立即丢弃。

## 6. 验收

必须证明：十批前缀可见性；每批一次决策和零至两个候选；四缓冲区用途互斥；REPLAY_REFIT预处理器拟合Update+Replay；延迟收益只更新已提交动作；任务重命名不改变决策；Qwen触发、重试和降级可复算；插件攻击失败关闭；模型训练—保存—加载同预测；Docker小于2GB且在4核8GB无GPU环境运行。

新RC冻结门为：A/B/C均超过静态基线，至少两项取得可复核显著改善；十轮和至少三次真实实验链完整；零未来泄漏、零非法特征、零不可加载模型；指标、最差阶段、CPU、RSS、参数量、模型大小、Token和影子收益齐全。30%改善是冲刺目标，不是允许伪造的硬门。
