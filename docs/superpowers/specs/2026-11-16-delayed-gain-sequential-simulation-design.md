# 延迟收益序贯适应模拟设计

## 目标与证据边界

建立一个新的本地代理模拟入口，复演“当前稳定模型先评价本轮未见数据，当前批次支持适应，下一批结算上一轮更新真实收益”的十轮闭环。该生命周期是用户确认的研究语义，不冒充正式SDK；最终官方隐藏测试保持不可见。

## 每轮事务

1. 仅物化第 `t` 轮无标签特征，使用稳定模型 `M(t-1)`预测并封存。
2. 开放第 `t` 轮标签，计算 `arrival_metric_t`。
3. 将任务方向归一化后的到达性能、历史到达性能、漂移和上一轮延迟收益传给EvidenceRouter/ActionPolicy。
4. ActionPolicy决定`retain`或训练一个候选。训练只读取本轮Update和可选合法Replay；当前Gate不参与训练。
5. SafetyGate只使用本轮Gate、Anchor和Replay保护证据部署或拒绝候选，形成`M(t)`。
6. 若第`t-1`轮部署过候选，在第`t`轮对完全相同到达样本同时运行`M(t-1)`和其直接前任影子模型，计算`delayed_gain_t`，归因给上一轮动作；额外推理成本记账。
7. 原子提交父链后进入下一轮。没有合法影子模型时延迟收益标记为不可用，不能伪造。

## 三类指标

- `arrival_metric_t`：`M(t-1)`在整批未见到达数据上的Prequential表现，允许进入决策证据。
- `candidate_gate_metric_t`：稳定模型与候选在本轮隔离Gate上的指标，只决定是否部署。
- `delayed_gain_t`：上一轮部署模型与其直接前任在本轮同样本上的配对主指标差，正值统一表示新模型更好。

外部确认集只在第10轮策略冻结后读取一次，不反馈策略、不回选轮次。公开或本地确认指标与正式隐藏测试严格分开。

## 数据流

- Gas继续使用父模型未见的自然批次及批内时间顺序；Batch 10只作已暴露本地确认。
- Bearing以未见轴承各自的归一化寿命进度切成十个连续阶段；同一轴承可跨轮，但未来阶段不可提前进入Replay。保留一个完整轴承作已暴露本地确认是本地资源限制，不宣称官方划分。
- Engine保持完整unit分组，unit不跨Update/Gate/确认边界。

## 决策与预算

新增`sequential`策略模式，不按任务名称硬编码动作。第1轮允许一个低成本候选建立适应基线；后续只在到达性能相对历史参考退化、上一轮延迟收益为负或连续未改善且预算允许时训练。候选上限沿用配置；每轮最多一个候选。PyTRiO只接收同样的结构化证据，不能覆盖预算与SafetyGate。

## 产物与验收

- 每轮保存预测封存、到达指标、候选Gate指标、延迟收益、动作、部署结果、CPU/RSS/Token和数据哈希。
- 测试必须证明：到达指标传入策略；未来不可见；Gate不训练；延迟收益只在下一批结算且使用同样本；retain无虚假收益；父链连续；确认只读一次。
- A/B/C完整十轮训练生成独立机器JSON、HTML与SwanLab离线记录。
- 结果只报告实际数值。若性能仍差，保留负结果，不用确认集调参。
