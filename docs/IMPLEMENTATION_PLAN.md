# BRACE-MSI 正式实施计划

> 当前执行基线为[D-052](DECISION_LOG.md)与[D-057](DECISION_LOG.md)：Qwen3.5-4B基础模型受控建议 + BRACE确定性双闭环 + 四缓冲区物理隔离 + 父checkpoint增强的身份盲CPU候选。`BRACE-MSI-0.5.0rc1`已完成本地验收；当前只等待正式平台映射与校验。下方早期Gate内容保留历史背景；若与本节冲突，以本节和[TASKS.md](TASKS.md)为准。

## 当前P0—P4实施顺序

### P0：官方训练链路与PyTRiO

1. 实现可注入的PyTRiO客户端、严格结构化提案、Token/延迟收据及确定性降级。
2. 将官方A/B/C检查点、历史读取、提案、隔离训练、独立评估、SafetyGate和部署/回滚接入同一Harness。
3. 仅允许白名单工具和配置键；模型输出不能直接成为shell/Python代码，不能绕过预算或SafetyGate。
4. 比赛专用入口、Base URL、密钥和事件字段全部配置化；未知项保持`BLOCKED`而非猜测。

### P1：三任务真实性能优化

Gas、Bearing、Engine分别进行误差诊断、低成本超参数/训练策略优化和必要的开源方法复现。三个任务可以使用不同模型、参数和动作，但共享Harness、安全边界、资源口径和证据标准。每项实验先冻结内部开发/确认数据，禁止只凭训练集或反复使用的公开验证集宣布成功。

### P2：十轮自主闭环

每任务完成十轮“历史读取—问题分析—提案—安全检查—训练或跳过—评估—上线/拒绝/回滚—记录”，至少三次真实候选训练。跳过必须基于证据而不是凑轮数。

### P3：正式对照

同一数据可见性、初始检查点和预算下比较官方静态、固定更新、BRACE无大模型、PyTRiO+BRACE及已验证论文方法；分别报告性能、最差阶段、恢复、CPU/RSS、Token/费用和回滚，不自造总分。

### P4：环境与交付

实际Docker构建、4核8GB断网运行、十轮无人值守、父集成训练/独立预测和干净容器复现已由0.5.0rc1完成。正式SDK适配、平台镜像/模型/续训校验及最终模型SwanLab记录仍为外部阻塞；不得以本地验收替代平台证据。

## 目标

构建一个在统一离线环境中无人干预运行、能驱动三个官方工业模型产生可复核性能改进、按预算执行真实候选实验并安全上线或回滚的训练Harness。PyTRiO Agent进入正式路线，但服务异常时系统仍必须由确定性策略完成安全降级 `[D-002]` `[D-035]` `[D-036]`。

## 阶段门

### Gate 0：事实与流程可恢复

- 文档、证据、任务、风险、实验和决策均有单一事实来源。
- 新会话只依赖仓库即可恢复。
- 完成标准：`DOC-001` 全部验收项通过。

### Gate 1：11月13日前最低可提交版本

采用宣讲给出的最早节点作为内部风险截止，不将其表述为已确认的学校截止 `[B-SCHEDULE-001]` `[H-005]`。

最低版本必须具备：

1. SDK事件适配层，可配置 `predict_then_feedback` 与 `labeled_train_then_predict`。
2. `TaskBootstrap` 能从官方初始模型或合法初训数据建立任务专属基线。
3. 三个公开任务均能完成初训、预测和指标计算；B包不得跨任务复用模型。
4. 至少三次真实候选训练/优化与合法评估事件；是否要求部署以正式规则为准。
5. 预算账本、模型能力声明、三层SafetyGate、检查点与回滚。
6. 4核8GB Linux CPU环境无人值守运行；镜像小于2GB且无预装权重。
7. SwanLab与本地审计记录符合正式规范，且不泄露私有数据。
8. 一键运行说明、依赖锁定、开源合规说明和校赛展示材料。

停止条件：任一P0合规项未通过时，停止新增算法和可视化，只修复闭环与提交风险。

### Gate 2：企业赛客观竞争力

- 与官方静态基线、最强静态CPU模型、固定更新、固定回放、每次HPO和性能触发式更新进行同协议比较。
- BRACE-MSI必须位于性能、最差阶段、周期与资源的Pareto前沿。
- 未证明优于性能触发式更新前，不增加复杂Agent模块。

停止条件：若复杂策略被简单对照全面支配，冻结展示增强，回到动作选择与预算分配。

### Gate 3：主观评审与决赛增强

- 完成跨任务泛化、关键消融、失败分析和工业安全论证。
- 只引入已在官方开发流证明价值的论文模块或模型服务。
- 形成设计论证、实验报告、PPT、视频和答辩题库。

- 用户个人100元预算仅在已有客观增益证据时启用 `[L-TEAM-001]` `[D-004]`。
- 本地RTX 4060 Ti属于开发能力，不改变正式CPU约束，也不决定赛题方向 `[L-HW-001]` `[D-005]`。
