# COMPETITION-CORE-EXP-001 本地性能与泛化矩阵

## 结论

本实验完成了官方A/B/C公开训练包与两个身份不透明同格式代理任务的五策略、十轮本地矩阵。运行均为本机CPU，不调用官方平台、PyTRiO或SwanLab，不读取隐藏数据。

- `A1`按跨任务平均收益选择`core_robust`。冻结后历史暴露公开验证上，A/B/C三项均超过静态父模型，但幅度分别只有约`+2.35% Macro-F1`、`-0.17% RMSE`和`-1.88% RMSE`。
- `A2`的画像自适应策略改善了B训练内部平均收益，但最差阶段仍不稳定，未成为winner。
- `A3`按跨任务最差阶段优先选择`core_stable`；B/C公开验证改善，但A Macro-F1低于静态父模型。因此风险优先开发winner不能直接替代最终正式策略。
- 两个同格式代理任务上，Competition Core候选均显著超过弱静态父模型；这只证明通用链路能学习，不证明官方隐藏泛化。

准确结论是：注册recipe和同作用域选择有效，但单一固定recipe策略不能同时支配A/B/C与代理任务。Task 11必须利用这些正负轨迹训练/验证Qwen实验决策，而不是把`core_robust`或`core_stable`硬编码成最终菜单。
