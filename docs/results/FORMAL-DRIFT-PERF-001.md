# FORMAL-DRIFT-PERF-001

`brace-msi:0.12.0rc1`的4核4GB验收暴露出资源缺陷：B第4轮候选训练与评估仅约`0.029s`，但进入状态RPC前累计约`347.087s`。根因是4个真实轮次块只形成4种唯一同步块划分，而实现对2047个大量重复的置换mask逐一重算特征统计。

修复只去重计算，再按原置换序列的inverse索引还原2047份null统计。置换次数、随机mask频次、maxT/BY、alpha、效应门和输出结构均未改变。以旧镜像B第4轮真实收据复算，`DriftReport`逐字段完全相同，耗时`347.087s → 9.068s`（约`38.28×`）。

旧镜像验收在A 10轮、B 5轮后主动停止，目录和失败证据保留；它不得冻结或上传。新代码需重新构建干净镜像并从头完成4核4GB验收、黑盒测试和独立审计。

验证：新增红灯测试在旧实现上观测到200次统计计算，修复后通过；漂移、诊断、正式轮受影响测试`49 passed`。机器摘要见同名JSON。
