## 失败分析与停止决策

1. A1失败来自预注册指纹转录错误，不是数据被篡改。新增配置契约测试要求所有指纹为64位小写SHA-256。
2. 统一回放与类平衡回放在开发流的平均指标均低于`current_only`，确认流也未反转；复杂性不值得进入Gas主线。
3. Batch 3和Batch 6候选多次因Batch 1锚点退化超限被拒绝，说明安全门确实阻止了局部改善但严重遗忘的更新。
4. 依据D-016和预注册停止规则，不继续扩大Gas回放搜索；保留`current_only + SafetyGate`作为Gas当前最低可用候选，最终价值等待隐藏评测确认。
