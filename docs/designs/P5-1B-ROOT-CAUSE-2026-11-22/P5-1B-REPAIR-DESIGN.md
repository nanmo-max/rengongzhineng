# P5-1B 最小修复设计

## 1. 修复目标

本设计不是实现批准，也不修改P5-1A。目标是用最少的独立变化解决已证实根因，并避免通过降低alpha、减少置换或放宽验收门制造表面通过。

## 2. 修复包及优先级

### R2-1：分离漂移结论与参考纳入资格（P0）

新增独立的参考纳入证据：

```text
ReferenceAdmissionDecision =
  monitor_has_no_drift_evidence
  AND data_quality_ok
  AND anomaly_screen_ok
  AND delayed_stability_check_ok
  AND reference_scope_compatible
```

`DriftStatus.STABLE`只表示本窗口没有通过漂移确认门，不再自动表示`reference_eligible=true`。状态机只接收显式纳入资格；异常值、缺失突增、契约异常可被标为“不确认漂移但禁止入池”。活动参考池仍保持不可变，隔离和恢复语义不变。

最小接口修改候选：给`ReferenceStateMachine.observe`增加显式`reference_eligible`，默认失败关闭；保留`data_quality_ok`处理硬错误。不得通过把异常值直接改判为漂移来绕过污染测试。

### R1-1：先补齐开发诊断收据（P0）

开发期每窗保存：

- 五个原始特征统计量；
- 置换零分布中心和尺度摘要；
- 标准化统计量与dominant statistic；
- 特征经验p、maxT/BY调整p；
- 被p值门、效应门还是连续确认门拒绝；
- 不含逐样本值，只保存聚合和哈希。

该修改只增加可解释性，不改变检测结果。没有这一步，不得声称已定位尺度检测器的具体数学瓶颈。

### R1-2：尺度/噪声统计候选（P1，开发期竞争）

仅在全新修复开发流比较以下候选，不预先宣布胜者：

1. 现有log-IQR基线；
2. 稳健Brown–Forsythe型绝对偏差统计；
3. log-MAD与log-IQR联合尺度统计；
4. 对持续中等变化使用互不重叠窗口的序贯证据累积。

全部候选必须在同一同步块校准和maxT框架内比较，保持`alpha_run=0.05`、窗口预算与2047次主臂置换。若增加统计量族，必须在特征内omnibus零分布中同步重算，不能事后挑最优统计量而不校正。

晋级要求同时满足：中等方差、噪声TPR改善；主无漂移和厚尾无漂移FPR不恶化；异常值不直接确认；CPU/RSS仍过工程门。

### R3-1：组感知的组成变化证据（P1）

扩展为可选输入合同：参考/当前的组ID或不可逆组摘要。输出分开：

- `group_proportion_shift`：组权重变化；
- `within_group_distribution_shift`：相同组内分布改变；
- `marginal_distribution_shift`：缺组信息时只能给出的边际事实。

组比例检验以独立组为单位；设备组不足、组标签跨窗不一致或只有行级伪组时返回`insufficient_group_support`。未知任务没有组元数据时保持现有边际检测，不按任务名称猜组。

### R4-1：重构校准选择语义（P0）

校准流程应先判断“边际p值从何而来且是否有效”，再决定跨特征校正：

```text
合法完整组/块交换性
  → 同步块置换边际p + maxT FWER

无maxT交换性，但存在经验证的有效边际p值
  → 有效边际p + BY FDR

两者都没有
  → INSUFFICIENT_CALIBRATION（失败关闭）
```

BY不得再称为自动修复交换性的工具。若仍使用经验p，置换数必须按`alpha/(d×H_d)`而不是仅按`alpha/10`校验分辨率；128维需要约139,088次置换，通常不符合CPU预算，因此不推荐暴力增加置换。优先考虑在明确独立组摘要上获得有效边际p；否则失败关闭。

### R5-1：增加相关结构验证规模（P0验证项）

这不是算法改动。每个维度×相关结构的无漂移独立流从6提高到至少35，建议40。运行级区间仍以流为重复单位；窗口FPR可汇总窗口，但不得把窗口当运行级独立样本。

## 3. 明确禁止的伪修复

- 不降低`alpha_run`控制要求或把0.005窗口门随意提高。
- 不取消maxT/BY或用未校正p值换取TPR。
- 不把P5-1A最终种子加入开发集。
- 不把同一流窗口当成独立流收窄置信区间。
- 不把异常值强制称为设备漂移。
- 不把组内多行称为多个独立设备组。
- 不把增加置换次数作为BY唯一修复；128维成本不可接受。

## 4. 变更隔离顺序

1. 仅补诊断收据，证明结果位于哪道门；检测输出应逐位一致。
2. 单独修参考纳入资格，验证异常值零污染；不改统计量。
3. 单独运行尺度/噪声统计候选开发竞争。
4. 单独增加组组成接口与测试。
5. 单独重构校准选择和BY语义。
6. 组合后才执行新的独立确认。

每一步一个主要变量，失败即保留证据并停止叠加补丁。

## 5. 预期副作用与缓解

| 修复 | 主要副作用 | 缓解方式 |
| --- | --- | --- |
| 参考纳入资格 | 参考池增长慢、早期历史不足 | 明确返回历史不足；不降低质量门 |
| 新尺度统计 | 厚尾分布误报、CPU增加 | 厚尾/异常值负对照；同置换校准；资源门 |
| 序贯累积 | 短暂变化残留、恢复变慢 | 只累积非重叠窗；恢复重置；alpha账本 |
| 组组成证据 | 组基数泄露、伪独立 | 只保存不可逆摘要；以完整组为单位 |
| BY语义重构 | 更多场景失败关闭 | 如实标记证据不足，不制造无效p值 |
| 扩大验证规模 | 增加验证时间 | 并行独立流；不降低置换精度 |
