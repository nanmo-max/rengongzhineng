# PERF-B-001 官方B包只读诊断

## 边界

- 数据与检查点来自`cpu-b-rul-20261110-v1`；原包只读。
- 本诊断使用官方检查点一次聚合预测和既有冻结候选日志，不启动新训练。
- `public/validation.jsonl`早已被官方基线与本项目历史实验使用，不是独立未见测试。

## 数据与模型事实

- 训练集7,032行、9根轴承；验证集1,679行、3根轴承，整轴承隔离。
- 训练轴承长度123—2,538快照；训练目标均值954.151分钟、标准差785.230。
- 验证轴承长度42、122、1,515；验证目标均值687.967分钟、标准差465.545。
- 模型是34→24 tanh→1 NumPy MLP，官方初始检查点已训练15 epoch，目标均值/尺度固定为训练集统计。
- 官方静态验证RMSE 681.159833、MAE 563.105841。预测均值322.583，整体偏差为-365.384分钟。

## 已有候选证据

`OFFICIAL-PACKAGE-DEV-001`中，原训练集续训1 epoch将RMSE从681.159833改善到657.645417、MAE从563.105841改善到550.039442；再续训到epoch 17/18的候选RMSE分别退化到663.87/674.04并被拒绝。因此不再搜索“更多同质epoch”。

## 下一可检验假设

训练数据由超长轨迹支配，低RUL目标也更密集。在不把轴承ID、快照号、总快照数或RUL派生量作为模型输入的前提下，比较：

1. 原始样本分布的1-epoch续训；
2. 每根轴承贡献相同期望样本数的组平衡重采样；
3. 依据ICML 2021 DIR官方LDS公式估计有效标签分布并作逆密度重采样。

方法先在`public/train.jsonl`的9根轴承上做3折“每工况留一1根轴承”验证；只有冻结胜者才对官方检查点做一次全训练集续训和历史暴露公开验证确认。
