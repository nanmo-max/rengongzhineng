# 官方赛题规则核验摘要

来源：`[O-RULE-001]`。本摘要来自2026-11-06对本地PDF渲染页的视觉核验，不替代原PDF。

## 第2页

- 工业数据随时间变化导致输入分布及输入输出关系漂移。
- 赛题目标是构建工业模型自进化系统，支持持续微调或工具Harness路线。
- 考察漂移监测与归因、路线判断、自动化工程、实验管理、可观测性、安全与受控改进。
- 队伍为3-5名学生，指导教师不多于2人。

## 第3页

- 企业赛第一阶段线上提交与客观评测，第二阶段为前20队线下演示答辩。
- 官方提供带标签公开训练/验证集、评测脚本和隐藏测试流。
- 系统需自动完成漂移监测、诊断、实验优化、评估上线和回滚。
- 训练、微调、调整与评估需按实验记录规范在云端平台完整记录。
- 提交模型配置与Harness镜像、实验记录链接/查询依据和系统运行说明。
- 驱动Harness的大模型表述为PyTRiO训练所得模型或PyTRiO Qwen3.8-27B。
- 正式评测在统一离线环境无人干预运行。

## 第4页

- 客观评价关注单位增益对应的算力/训练额度、标注配额和大模型Token。
- 主观评价关注方法设计、实验分析、安全与工业落地、报告与答辩。
- 基础门槛包括无人干预、完整实验记录和不低于静态基线。
- Python 3.10及以上；官方数据规模较小并提供预提取特征，基础任务普通CPU可完成。
- 官方支持包括数据、PyTRiO额度、SDK/规范和SwanLab云端实验记录平台。

## 第5页

- 企业赛阶段提供PyTRiO额度，SwanLab已上线并免费开放。
- 禁止泄露/转借账号、攻击平台、获取隐藏测试集、植入恶意代码或未授权外网访问。
- 开源和预训练资源必须遵守许可证。
- 规则未尽事项及冲突以组委会规定为准。

## 不在该PDF中确认的内容

- 4核8GB、2GB镜像、无GPU；
- 三个具体公开任务名称；
- 至少三次迭代；
- SwanLab必须公开；
- 客观35分、主观65分；
- 11月9日、11月13日、11月15日等专项节点。
