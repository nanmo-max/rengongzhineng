# REGRESSION-SPRINT-001 预注册

目标是在不使用官方十次试运行的前提下，为官方B/C公开训练包各完成一次固定上限的候选矩阵，而不是继续串行小试。

- 矩阵：续训轮数`1/3/5` × 学习率倍率`0.3/1/3`，每任务9个候选；不追加搜索。
- B按整轴承划分：`*_1`训练、`*_2`开发选择、`*_3`一次确认。
- C按整发动机划分：FD001+FD002训练、FD003开发选择、FD004一次确认。
- 每任务先在训练组从头训练15 epoch共同父模型，9个候选共享该父模型；只用开发组排序，确认组只评估冻结的一个候选。
- 若开发或确认门失败，固定退回`1 epoch × 1.0`低成本方案；不以“再试几个”扩大搜索。
- 冻结配置后，最多从官方初始检查点运行1个全公开训练集续训候选，并在已历史暴露的公开validation上作SafetyGate。该结果不是独立测试或官方成绩。
- 最终门：RMSE相对静态至少改善0.1%，且MAE不退化；否则保留官方静态检查点。
- 每任务最多11次训练（1父模型+9矩阵+1最终候选），单次180秒；官方试运行、PyTRiO、SwanLab均为0。
- 原始包只读；所有派生切分、检查点和收据写入独立运行目录。失败候选保留。Gas不重训。
